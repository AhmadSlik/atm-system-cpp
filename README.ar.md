# نظام ATM — C++ Console App 🏧

محاكاة لجهاز ATM موجهة للعميل نفسه — بدل ما الموظف يدير بيانات العملاء، هون العميل بيسجّل دخوله بنفسه ليسحب، يودع، ويتحقق من رصيده. البرنامج بيقرا ويكتب على نفس ملف `ClientRecord.txt` يلي يستخدمه [نظام البنك](https://github.com/AhmadSlik/bank-system-cpp): مصدر بيانات واحد، وواجهتين مختلفتين تماماً.

> المشروع الثاني من كورس **Algorithms & Problem Solving Level 4** (الكورس الثامن من خارطة الطريق للدكتور محمد أبو هدهود).

## المميزات

- تسجيل دخول العميل بـ **رقم الحساب + رمز PIN** (مش اسم مستخدم/كلمة مرور متل الموظف — هاي الواجهة الذاتية للعميل)
- **سحب سريع** — اختيار من مبالغ جاهزة (20، 50، 100، 200، 400، 600، 800، 1000)
- **سحب عادي** — أي مبلغ تحدده، بشرط يكون من مضاعفات 5 وضمن رصيدك
- **إيداع** — إضافة مبلغ لحسابك الخاص
- **تحقق من الرصيد**
- بيشارك نفس ملف العملاء مع نظام البنك، فأي إيداع هون بيظهر هناك كمان

## طريقة التشغيل

```bash
g++ main.cpp -o atm_system
./atm_system
```

> البرنامج يستخدم أمر خاص بنظام Linux (`system("clear")`) لمسح الشاشة، فأفضل تشغيل له على Linux أو macOS. بيحتاج ملف `ClientRecord.txt` فيه حسابات موجودة أصلاً (متولّدة من نظام البنك) بنفس المجلد.

## المفاهيم المطبّقة

- Function Overloading — فيه دالتين بنفس الاسم `CheckBalance`، وحدة لسجل واحد ووحدة تبحث بقائمة وتنادي التانية؛ الـ compiler بيختار الصح حسب نوع المدخلات
- قاعدتين تحقق مجموعين بشرط واحد — السحب لازم يكون ضمن الرصيد *و* من مضاعفات 5، متل ما جهاز ATM حقيقي بيوزع بس فئات نقدية ثابتة
- إعادة استخدام نفس صيغة الملف لبرنامجين مختلفين تماماً (نظام الموظف، وATM ذاتي الخدمة) بيشاركوا نفس بيانات العملاء بدون أي تحويل
- Recursion للتنقل بين الشاشات وكمان لإعادة محاولة بحث فشل
